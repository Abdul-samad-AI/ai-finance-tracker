## 🚀 Project Overview

**AI Finance Tracker** is a full-stack web application designed to help users **track expenses, analyze spending patterns, and gain financial insights**.

The project is intentionally built in **phases**, following real-world engineering workflows.  
This repository currently represents **Phase 1 — Frontend Foundation**.

> 🔧 Backend (Django REST API) and AI-based analysis will be integrated in later phases.

---

## 🎯 Current Phase: Frontend API Integration (Completed till Day 3)

This phase focuses on building a **robust frontend foundation** capable of handling real API interactions and production-like UI behavior.

### ✅ What’s Implemented

✔ Login UI with controlled inputs  
✔ API interaction using Axios (`POST` request)  
✔ Loading state with disabled actions  
✔ Error handling without UI crashes  
✔ Clean `async/await` pattern  
✔ Real HTTP request–response flow  
✔ Scalable and backend-ready component structure  

> This phase demonstrates **professional frontend engineering practices**, not mock UI behavior.

---

## 🧠 Core Architecture Demonstrated

```text
User Input
   ↓
React Component
   ↓
Axios HTTP Request
   ↓
API Endpoint
   ↓
JSON Response
   ↓
React State Update
   ↓
User Feedback (Loading / Success / Error)
````

This same architecture will later support:

* Expense CRUD APIs
* Analytics endpoints
* AI-based insights
